# DinoPédia

Enciclopédia colaborativa de dinossauros.

## Abrir o site (sem o PC ligado)

O código está em: https://github.com/lucasmelodavi/Dinopedia

Para o site ficar no ar 24h, publique no Render:

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/lucasmelodavi/Dinopedia)

1. Entre no Render com o GitHub.
2. Clique em **Apply**.
3. Espere uns minutos.
4. Copie o link `https://dinopedia.onrender.com` e mande para os amigos.

No plano grátis o site pode demorar ~1 minuto na primeira abertura do dia.

## Local

Site: `npm run dev` (http://localhost:5173)

API: na pasta `backend`, `node app.js` (http://localhost:3000)
